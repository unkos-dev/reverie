# Mona Sans

Mona Sans v2.0.27 is self-hosted under the SIL Open Font License 1.1. The complete licence text is in `OFL.txt`.

Source:
[official font release](https://github.com/github/mona-sans/releases/download/v2.0.27/mona-sans-webfonts-v2.0.27.zip).
The variable fonts supply weight, width and optical size axes.

`files/MonaSansVF-Italic.woff2` is the variable italic face from the same release archive.

`files/SHA256SUMS` records the SHA256 of the unmodified release files. Verify it from `files/` with
`sha256sum -c SHA256SUMS`.
