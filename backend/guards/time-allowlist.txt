# time crate usage allowlist
#
# This file is the canonical registry of files permitted to reach the
# `time` crate. First-party code uses chrono (`DateTime<Utc>` for
# instants, `NaiveDate` for calendar dates); see backend/AGENTS.md and
# adr/2026-08-05-first-party-datetime-crate.md. CI greps backend/src/ for
# `time::` paths and rejects any line not containing a fixed string from
# this file (`grep -v -F -f`).
#
# The guard matches qualified `time::` paths, not just `use time`, so a
# file that reaches the crate through a fully-qualified call is caught
# too. It does not distinguish code from prose: a doc comment naming a
# `time::` type in an unlisted file trips it. Rephrase the comment rather
# than adding an entry, unless the file genuinely uses the crate.
#
# Adding an entry: include reviewer justification in the PR description
# adding it. The only accepted carve-out class today:
#   1. A third-party API whose signature takes a `time` type and offers no
#      chrono alternative. The conversion happens at that boundary; the
#      `time` value must not spread into first-party models, DTOs, or
#      signatures.
#
# Each non-comment line is a substring; if it appears in a `grep -rn`
# output line `path:line:content`, that usage is allowed.
